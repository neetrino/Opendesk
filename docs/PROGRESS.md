- [x] Голосовые в чате: tap-to-record, затем отправить; в камере tap=фото / hold=видео

- [x] Рабочий тред карточки: реакции, reply, pin, edit/delete, @mention, копирование текста, поиск, разделители, вопросник, задача из сообщения
